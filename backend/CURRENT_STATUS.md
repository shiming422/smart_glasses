## 当前推荐使用方式

1. 让 `esp32_receive` 开机并连上 `C413C413_5G`，确认其 HEVC/TCP 地址为 `tcp://192.168.0.121:9000`。
2. 让 `compile/compile.ino` 对应设备连上同一 Wi-Fi，作为音频 + IMU 终端运行。
3. 在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start_aiglass_rv1106.ps1
```

4. 浏览器打开 `http://127.0.0.1:8081`。

## 风险与说明

- “代码已实现但依赖外部模型/API” 表示仓库中已有对应能力，但是否能完整跑通还依赖模型文件、密钥、设备和现场环境。
- 当前文档只把 `hevc_tcp` 视为默认视频路径；`/ws/camera` 仅保留为历史入口占位。
- 历史探针、日志、桥接脚本和临时恢复文件应视为清理对象，不再作为功能组成部分。
